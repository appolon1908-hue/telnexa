# Middleware billing events

Events include `billing.wallet.credited`, `billing.wallet.debited`, `billing.reservation.created`, `billing.reservation.released`, `billing.charge.finalized`, `billing.payment.received`, `billing.invoice.issued`, `billing.invoice.paid`, `billing.invoice.overdue`, `billing.low_balance`, and `billing.account.suspended` in envelope version `1.0`.

The outbox worker posts only to `BILLING_MIDDLEWARE_URL` on `10.40.0.1`. It obtains a short-lived (maximum 300-second) `telnexa-gateway` client-credentials token from the canonical Keycloak issuer, uses mTLS, and applies the Middleware canonical v1 HMAC over `version + method + path + timestamp + event_id + source + body_sha256`. Secrets are mounted files supplied by the external secret authority; they are not ordinary environment values. `X-Codestra-*` headers bind the event, tenant, source, correlation and idempotency identities. Middleware owns replay protection and Odoo/n8n routing. Telnexa never writes Odoo PostgreSQL or calls arbitrary n8n webhooks.
