# Invoices and statements

Invoices use tenant-scoped sequential numbers, periods, issue/due dates, decimal subtotal/tax/credits/total/paid values and draft/issued/paid/partially_paid/overdue/void/credited states. Lines retain usage and rate evidence. JSON APIs are tenant filtered. PDF/CSV rendering and scheduled invoice issuance remain an activation item and must be jurisdiction-configured before production use. Statements are ledger-derived opening, debit, credit, reservation/release, payment, adjustment and closing views.
