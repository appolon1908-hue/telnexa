# Billing backup and restore

`scripts/backup.sh` takes PostgreSQL custom-format dumps alongside the configuration, secret, mTLS, Jasmin, Redis, and RabbitMQ recovery artifacts. Plaintext staging is restricted to tmpfs. The script creates and verifies an internal `SHA256SUMS`, encrypts the complete archive to the approved GPG public recipient, writes only the encrypted archive and outer checksum to persistent local storage, then copies and verifies both on a distinct mounted off-host source. Before schema change, run the backup and verify `pg_restore --list` in an isolated recovery job.

Restore requires the encrypted archive and checksum, `CONFIRM_RESTORE=RESTORE_TELNEXA`, and either `TELNEXA_BACKUP_PRIVATE_KEY_FILE` or an approved `TELNEXA_BACKUP_GNUPGHOME`. It decrypts only into tmpfs, verifies the internal manifest before stopping services, does not overwrite the reviewed Git checkout from archived configuration, recreates the billing and Keycloak databases, uses `pg_restore --exit-on-error`, restores RabbitMQ definitions and bounded volume data, deploys only approved digest-addressed images through `scripts/start.sh`, and runs health checks. Validate ledger totals, wallet reconciliation, rate counts, invoices, payments, outbox, identity flows, and simulator sends on an isolated clone before production recovery.
